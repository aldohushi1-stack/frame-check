# House rules (example)

Copy this file to `house-rules.md` beside `SKILL.md`, then edit. Frame Check reads it when present
and applies these on top of its own procedure. Keep each rule to one line.

## Voice

- Short, warm, plain. One-word openers are fine ("Bless.", "Noted.").
- No jargon: "leverage", "solutions", "seamless", "AI-powered".

## Channel rules

- LinkedIn posts carry no hashtags; the keywords go in the opening line.
- Emails: links as bare text (example.com/page), never wrapped in tracking redirects.

## The ask

- For warm leads, the ask is a face-to-face sit-down, not another message.
- One ask per message. Never two.

## Never

- Invented testimonials, quotes, stats, awards or client names.
- Fake scarcity or deadlines.
- Reframing something that already happened.
